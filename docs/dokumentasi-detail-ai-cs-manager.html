BAB 1 — Ringkasan Eksekutif

1.1 Perubahan dari v1.0 ke v2.0

AI Customer Service Manager (AI CS Manager) telah berkembang secara signifikan dari prototipe statis (v1.0) menjadi aplikasi fungsional yang terhubung ke database nyata, WhatsApp API, dan AI Engine.

Aspek Dokumentasi Awal (v1.0) Kondisi Saat Ini (v2.0)
Data Semua statis/hardcoded ✅ Database PostgreSQL (Supabase)
Autentikasi Belum ada ✅ Login real dengan bcrypt & session
WhatsApp Rencana saja ✅ KirimDev API terintegrasi
AI Engine Rencana saja ✅ SumoPod API (OpenAI-compatible)
RAG Pipeline Konsep saja ✅ pgvector + embedding + vector search
Backend Belum ada ✅ NestJS fully functional
Deployment Localhost saja ✅ Vercel (backend) + Supabase (DB)

2.3 Alur Kerja Sistem

Alur Pesan Masuk (Inbound) — ✅ Sudah Berjalan

1
Pelanggan mengirim pesan
Pelanggan mengirim pesan WhatsApp ke nomor bisnis perusahaan.
2
KirimDev menerima & forward
Platform KirimDev mengirimkan webhook ke backend (POST /api/webhook/kirimdev).
3
Backend menyimpan pesan
Pesan disimpan ke database. Contact & Conversation dibuat (jika baru) atau dilanjutkan.
4
Ambil konteks
Backend mengambil 20 pesan terakhir dari percakapan + konfigurasi AI Agent yang aktif.
5
RAG — Pencarian Knowledge Base
Generate embedding dari pertanyaan via SumoPod API, lalu vector similarity search di pgvector. Ambil top 5 chunks dengan similarity > 0.7.
6
AI Generate Jawaban
SumoPod memproses: system prompt + knowledge context + conversation history → hasilkan jawaban + confidence score.
7
Kirim balasan
Balasan dikirim ke pelanggan melalui KirimDev API → pelanggan menerima di WhatsApp.
8
Simpan & update
Pesan keluar disimpan ke DB, confidence score dicatat, status conversation diupdate.
📌 Penting
Seluruh alur ini berjalan otomatis. Dari pelanggan mengirim pesan hingga menerima balasan AI, prosesnya memakan waktu kurang dari 5 detik.

5.3 Takeover & Release

Takeover: AI → Manusia

1
Identifikasi percakapan
Cari percakapan dengan status NEED_HUMAN atau confidence score rendah.
2
Klik "Assign to Me"
Pada detail percakapan, klik tombol assign untuk mengambil alih percakapan.
3
Handle manual
Balas pesan dari dashboard atau WhatsApp di HP. Status berubah ke HUMAN_HANDLING.

Release: Manusia → AI

  • Klik tombol "Release to AI" pada detail percakapan
  • Status berubah kembali ke AI_HANDLING
  • AI akan kembali merespons pesan-pesan berikutnya
⚠️ Perhatian
Pastikan masalah pelanggan sudah terselesaikan sebelum melepas kembali ke AI. Jika pelanggan masih membutuhkan bantuan khusus, tetap handle secara manual.

7.2 RAG Pipeline

RAG (Retrieval-Augmented Generation) adalah teknologi kunci yang membuat AI bisa menjawab berdasarkan data perusahaan:

💡 Cara Kerja RAG (Sudah Terimplementasi)
  1. Indexing: Dokumen dipecah menjadi chunks (1000 karakter, 200 overlap) dan dikonversi menjadi vector embedding via SumoPod API
  2. Retrieval: Saat ada pertanyaan, sistem men-generate embedding dari pertanyaan dan melakukan vector similarity search di pgvector (top 5, similarity > 0.7)
  3. Generation: AI menggunakan chunks yang ditemukan sebagai konteks + system prompt + conversation history untuk menghasilkan jawaban akurat

Set Default✅Pilih agent default

Contoh System Prompt

Kamu adalah customer service AI dari [Nama Perusahaan], sebuah toko online yang menjual produk elektronik.

PERANMU:
- Menjawab pertanyaan pelanggan dengan ramah dan profesional
- Membantu pelanggan menemukan produk yang tepat
- Memberikan informasi harga, stok, dan spesifikasi produk

ATURAN:
- Selalu gunakan Bahasa Indonesia yang sopan
- Jika tidak tahu jawaban, katakan "Mohon maaf, saya perlu mengecek dengan tim kami"
- Jangan pernah memberikan informasi harga yang tidak ada di database
- Jika pelanggan komplain, eskalasi ke CS manusia

PERSONA:
- Nama: Aira
- Tone: Friendly tapi profesional
- Emoji: Gunakan secukupnya (🙏😊)
